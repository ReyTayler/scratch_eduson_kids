# Генерация изображений. Часть 1

Урок 4 модуля «Нейросети и AI-проекты». Возраст 7–9 лет, 60 минут, 24 слайда. Дети создают главного персонажа и место действия своей игры в Алисе AI. Картинки пригодятся для постера на уроке 5.

## Как провести

- Откройте [сценарий преподавателя](Сценарий%20урока.html) в отдельном окне или на втором устройстве. Исходник сценария — `Сценарий урока.md`.
- В Zoom или Телемосте показывайте окно с [экраном для детей](dist/audience.html). Стрелки листают слайды. Нажимайте варианты ответа после ответа детей. У фиолетовых раскрываемых элементов есть метка «Нажмите».
- [Презентация с заметками](dist/index.html) открывает панель по кнопке «Преподавателю» или клавише N. Окно заметок и окно показа листаются отдельно. На слайдах 12, 13 и 15 можно скопировать материал для чата урока. На 14, 15 и 18 кнопка «Запасной учебный ответ» открывает учебный рисунок. Клавиша D открывает доску.
- Для общего сбоя откройте учебную картинку отдельно и покажите её детям. При сбое у отдельного участника перешлите рисунок взрослому по согласованному каналу. Детский экран и все учебные файлы работают без сети. Для практики в Алисе AI требуется интернет.

## Сборка и проверка

Запустите из папки урока. Для проверки нужны Python с Playwright и Pillow и браузер Microsoft Edge. Снимки проверки сохраняются в `qa/`.

```powershell
python make_svg.py
python build.py
python check.py
python package.py
```

Архив «Генерация изображений 1 — 60 минут.zip» создаётся в корне проекта. Для локального показа распакуйте архив целиком и откройте HTML через браузер.

# Текстовый промтинг. Часть 1

Онлайн-урок для детей 7–9 лет. 26 слайдов, 60 минут. Сценарий: `Сценарий урока.md`.

## Открыть урок

Откройте `dist/index.html` в Edge или Chrome. Установка и сервер не нужны, шрифты встроены. На экране сразу слайд. При движении мыши появляются кнопки.

Кнопка **«Преподавателю»** открывает спикерскую речь и действие детей поверх слайда. Перед демонстрацией экрана закройте заметки. Файл `dist/audience.html` содержит только слайды, без речи.

| Управление | Действие |
|---|---|
| Влево / вправо | Предыдущий / следующий слайд |
| N или Т | Открыть / закрыть заметки |
| Escape | Закрыть заметки |
| Home / End | Первый / последний слайд |
| F или А | Полный экран |
| D или В | Открыть / закрыть доску |

Интерактив только прямо на слайде, и нажимается только то, что приподнято. Кнопки-ответы с тёмным нижним краем на слайдах 4, 6, 7, 8, 9, 11 и 12: нажмите ответ, и появится результат. Элементы с меткой «Нажмите» на слайдах 6, 8, 10, 14 и 23: нажатие показывает продолжение, метка исчезает. Повторное нажатие ничего не скрывает. При перелистывании всё сбрасывается. Пока открыта доска, нажатия по слайду не работают: сначала закройте её.

В заметках слайдов 13, 14, 15 и 18 есть кнопка **«Скопировать для чата урока»**: она копирует ссылку или образец промта. На слайдах 14–18 есть кнопка **«Запасной учебный ответ»** на случай, если Алиса AI недоступна. Это подготовленный текст, а не ответ сервиса.

## Перед уроком

Раздел «Подготовка преподавателя» в сценарии обязателен: согласие законного представителя (п. 1.7 условий сервиса), взрослый рядом, проверка Алисы AI и значков интерфейса. Значки на слайдах 13 и 19 нарисованы по описанию из справки, с настоящим интерфейсом их нужно сверить.

## Сборка

```powershell
python build.py
python check.py
```

`build.py` берёт речь, время и действие из сценария, а содержимое экрана из своего описания слайдов и папки `svg`. При изменении текста на экране правьте `build.py` и описание слайда в сценарии вместе.

`check.py` проверяет все слайды в Edge: переполнения, размер текста в схемах, нажатия на ответы и элементы, заметки, запасной ответ, доску, отсутствие речи в `audience.html`. Снимки сохраняются в `qa`, в git не входят. Это браузерная проверка, а не проведение урока в видеоконференции.

Основа оформления: https://github.com/terenta/eduson-kids-design-book. Файлы `designbook-*`, `web-60.css`, `board.py`, `vendor` и `font-licenses` скопированы из урока `ai-intro` без изменений. `web.js` основан на `web-60.js` и дополнен нажатиями на слайде.

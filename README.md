# Модуль 9 «Нейросети и AI-проекты»

Презентации уроков для преподавателей Eduson Kids. Корневой `index.html` показывает список уроков и открывает нужную презентацию. Сборка сайта не нужна: он состоит из готовых HTML-файлов.

## Публикация

Settings → Pages → Deploy from a branch → `main`, папка `/ (root)`. Адрес сайта: https://reytayler.github.io/scratch_eduson_kids/

Файл `.nojekyll` отключает обработку Jekyll, файлы публикуются как есть. Репозиторий открытый, поэтому речь преподавателя и сценарии доступны всем, у кого есть ссылка.

## Как добавить или обновить урок

1. Положите готовую презентацию в `<папка урока>/dist/index.html`. Ссылки внутри должны быть относительными.
2. В корневом `index.html` замените строку с пометкой «Готовится» на блок с кнопкой: скопируйте блок готового урока, укажите длительность и число слайдов.
3. Сделайте коммит и `git push`. Сайт обновится через несколько минут.

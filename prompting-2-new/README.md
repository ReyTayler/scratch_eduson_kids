# Текстовый промтинг. Часть 2

Онлайн-урок для детей 7–9 лет. 25 слайдов, 60 минут. Сценарий: `Сценарий урока.md`, для чтения в браузере — `Сценарий урока.html`.

Тема: роль и образец в промте, что Алиса AI учитывает в одном чате, галлюцинация, проверка факта по надёжному источнику, замена неудачного вопроса. Мини-проект: «Текстовый AI-квиз» про планеты, ответы проверяются по странице NASA «Planets».

## Открыть урок

Откройте `dist/index.html` в Edge или Chrome. Установка и сервер не нужны, шрифты встроены. На экране сразу слайд. При движении мыши появляются кнопки.

Кнопка **«Преподавателю»** открывает спикерскую речь и действие детей поверх слайда. Перед демонстрацией экрана закройте заметки. Файл `dist/audience.html` содержит только слайды, без речи.

| Управление | Действие |
|---|---|
| Влево / вправо | Предыдущий / следующий слайд |
| N или Т | Открыть / закрыть заметки |
| Escape | Закрыть заметки |
| Home / End | Первый / последний слайд |
| F или А | Полный экран |
| D или В | Открыть / закрыть доску |

Интерактив только прямо на слайде, и нажимается только то, что приподнято. Кнопки-ответы с тёмным нижним краем на слайдах 4, 5, 7, 9, 10, 11 и 12: нажмите названный ответ, и кнопка станет зелёной с ✓ или красной с ✗; после верного ответа появится пояснение. Элементы с фиолетовым краем и меткой «Нажмите» на слайдах 6, 7, 8 и 22: нажатие показывает продолжение, метка исчезает. Повторное нажатие ничего не скрывает. При перелистывании всё сбрасывается. Пока открыта доска, нажатия по слайду не работают: сначала закройте её.

В заметках слайдов 13, 14, 15 и 18 есть кнопка **«Скопировать для чата урока»**: она копирует ссылку или промт. На слайдах 14, 15, 16, 18 и 21 есть кнопка **«Запасной учебный ответ»** на случай, если Алиса AI недоступна. Это подготовленный текст, а не ответ сервиса.

## Перед уроком

Раздел «Подготовка преподавателя» в сценарии обязателен: согласие законного представителя (п. 1.7 условий сервиса), взрослый рядом, отключённое персонализированное общение, проверка промтов в Алисе AI, сверка страницы NASA с переводом на слайдах 11 и 16.

## Сборка

```powershell
python make_svg.py
python build.py
python check.py
python package.py
```

`make_svg.py` рисует учебные схемы в папку `svg`. `build.py` берёт речь, время, действие, цель и промты для копирования из сценария, а содержимое экрана из своего описания слайдов и папки `svg`; он же собирает `Сценарий урока.html`. При изменении текста на экране правьте `build.py` и описание слайда в сценарии вместе. Текст промта на схеме `s14-template.svg` должен совпадать с промтом для чата урока на слайде 14.

`check.py` проверяет все слайды в Edge: переполнения, размер текста в схемах, нажатия на ответы и элементы, сброс при перелистывании, стрелки после нажатия кнопок, заметки, запасной ответ, доску, отсутствие речи в `audience.html`. Снимки сохраняются в `qa`, в git не входят. Это браузерная проверка, а не проведение урока в видеоконференции. `package.py` собирает архив `Текстовый промтинг 2 — 60 минут.zip` в корне репозитория.

Основа оформления: https://github.com/terenta/eduson-kids-design-book. Файлы `designbook-*`, `web-60.css`, `board.py`, `vendor` и `font-licenses` скопированы из урока `prompting-1-new` без изменений. `web.js` тот же, что в уроке 2; `lesson.css` дополнен стилями этого урока.

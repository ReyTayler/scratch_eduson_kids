# Модуль 9, уроки 1–3

Программа «Scratch и нейросети», 7–9 лет. Каждый урок идёт 45 минут, из них 25 минут практика в Алисе AI. План всего модуля лежит в файле `../План модуля 9.md`.

| Папка | Урок | Результат |
|---|---|---|
| `ai-intro` | 1. Введение в нейросети | Файл «Мой герой» |
| `../prompting-1` | 2. Текстовый промптинг, часть 1 | Мини-проект «Сценарий игры» |
| `../prompting-2` | 3. Текстовый промптинг, часть 2 | Мини-проект «Текстовый AI-квиз» |

Цель и ожидаемые результаты показаны на слайде 2 каждого урока. В заметках к этому слайду записаны образовательные результаты и то, где их проверить.

## Как проводить

Откройте `dist/index.html`: презентация работает без установки. Для практики нужны интернет и доступ к https://alice.yandex.ru/.

Клавиши: ← и → листают слайды, N открывает заметки, F включает весь экран. Заметки это сценарий для преподавателя, там же список подготовки к уроку на слайде 1.

Рабочий лист `dist/practice.html` открывают один раз, кнопкой на слайде «Открываем». Он не связан с Алисой: дети копируют в него запросы и ответы из чата. После обновления страницы записи пропадают, поэтому в конце практики файл обязательно сохраняют. Загрузки запрещены? Перенесите записи в разрешённый документ. Файл урока 1 нужен на уроке 2.

## Перед уроком

- Проверьте доступ к Алисе AI, отправку двух сообщений в одном чате и правила сервиса для вашей группы.
- Дети не регистрируются и не получают пароль взрослого. Если работаете под своим аккаунтом, отключите «Персонализированное общение».
- На индивидуальном занятии ребёнок работает со взрослым. В группе нужен подготовленный доступ на каждую пару.
- Для урока 3 подготовьте источник по каждой теме викторины: детскую энциклопедию или проверенный сайт.
- Сервис недоступен? Перенесите живую практику: бумажный запрос или готовый пример её не заменяют.

## Как поправить и пересобрать

Текст уроков хранится в `lesson.json` каждой папки. Рабочие листы правятся прямо в `dist/practice.html`. Пересборка (Python 3, без сторонних библиотек):

```
python build.py
python build.py ../prompting-1
python build.py ../prompting-2
```

Сборка обновляет `dist/index.html` и `Текст урока.md`. Оформление и код слайдов общие: `style.css`, `app.js`, `design_template.py` в этой папке.

`review-1.md` и `review-2.md` относятся к прошлой версии урока 1 и сейчас устарели.

Основа оформления: https://github.com/terenta/eduson-kids-design-book. Программа: страница 13 PDF «Scratch и нейросети». Источники теории перечислены в плане модуля.

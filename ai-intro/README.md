# Введение в нейросети

Самостоятельный онлайн-урок для детей 7–9 лет. 24 слайда, 60 минут. Предварительные знания программирования не требуются.

## Открыть урок

Откройте `dist/index.html` в Edge или Chrome. На экране сразу появляется слайд, без пульта, предпросмотра и боковой панели. Фирменный каркас Eduson Kids сохранён. Установка и сервер не нужны, шрифты встроены и работают без интернета.

При движении мыши появляются компактные кнопки; через короткую паузу они скрываются. Кнопка **«Преподавателю»** открывает спикерскую речь поверх слайда. Изначально заметки закрыты. Там же находятся содержание, размер текста, копирование запросов и учебный исправленный ответ.

| Управление | Действие |
|---|---|
| Влево / вправо | Предыдущий / следующий слайд |
| N или Т | Открыть / закрыть заметки |
| Escape | Закрыть заметки |
| Пробел | Показать / скрыть ответ задания |
| Home / End | Первый / последний слайд |
| F или А | Полный экран |
| D или В | Открыть / закрыть доску |
| Ctrl+Z / Ctrl+Shift+Z | Отменить / вернуть рисунок на доске |

Открытые заметки видны в том же окне. Перед демонстрацией детям закройте их. Дополнительный файл `dist/audience.html` содержит только слайды, без спикерской речи и кнопки заметок. Обязательного переключения между окнами нет.

## Доска

Кнопка **«Доска»** или клавиша D открывают панель инструментов поверх слайда: ручка, маркер, стрелка, рамка, указка, ластик, пять цветов, отмена, чистый лист и очистка слайда. Панель есть и в `dist/index.html`, и в `dist/audience.html`, работает без интернета. Изначально она скрыта. Рисунки стираются при смене слайда и никуда не сохраняются; чистый лист один на презентацию и живёт до закрытия вкладки или доски. Escape закрывает только доску.

Модуль: `board.py`, подключается в `build-60.py` и `build.py`. Библиотека drauu лежит в `vendor/`, лицензия MIT: `vendor/drauu-LICENSE.txt`.

## Содержание

Распознавание объясняется на цифрах, написанных от руки: чем нейросеть отличается от обычной программы, подписи к примерам, четыре шага обучения, ошибка из-за случайно совпавшего цвета и какие примеры нужно добавить. Все рисунки и схемы сделаны в SVG. Презентация сама модель не обучает и не запускает.

Практика: каждый ребёнок или пара сам работает в Алисе AI и делает первые шаги в работе с нейросетью. Слайды 15–20: открыть чат, написать запрос по образцу, проверить ответ, уточнить его в том же чате, попросить сочинить загадку в новом чате и написать свой запрос без образца. Записей на бумаге нет.

Тайминг: приветствие 5 минут, знакомство с темой 5, новая тема 20, пауза и проверка 5, практика 20, итоги и домашнее задание 5. Речь, вопросы, ожидаемые ответы и организация работы по минутам записаны в `Текст урока.md`.

Перед уроком проверьте Алису AI на устройствах детей: открывается ли сайт, нужен ли вход, подходят ли условия сервиса для этого возраста. Рядом с ребёнком нужен взрослый для помощи с чтением и копированием. Если сервис недоступен, используйте учебный ответ из заметок и перенесите настоящие запросы на следующее занятие.

Домашнее задание на слайдах 23–24, около 15 минут: ребёнок выбирает формат (загадка, мини-сказка, открытка или свой), вместе со взрослым проходит в Алисе AI запрос, проверку и уточнение. Ответы в примере на слайде 24 подготовлены для урока. Оформление по шаблону дизайнбука.

## Исходники и сборка

```powershell
python author-60.py
python build-60.py
python package-60.py
```

`author-60.py` формирует `lesson-60.json` и `Текст урока.md`. `build-60.py` накладывает содержание на HTML. `slide-art-60.py` содержит схематичные изображения и компоненты. `web-60.js` управляет слайдами и необязательными заметками, `web-60.css` оформляет только элементы управления.

Основа оформления: https://github.com/terenta/eduson-kids-design-book. Неизменённый CSS исходного каркаса: `designbook-base.css`. Укладка материала в шаблоны: `designbook-slides.css`. SVG-спрайт и волны также взяты из репозитория. Источник и контрольная сумма: `designbook-source.json`. Шрифты Inter Tight, Inter и JetBrains Mono встроены; лицензии находятся в `font-licenses/`.

Проверка: `python check-60.py` при наличии Python Playwright, Pillow и локального Edge. Проверяются все 24 слайда, отсутствие переполнений, показ только слайдов по умолчанию, открытие и закрытие заметок, клавиатура, содержание, узкий экран, встроенные шрифты и доска. Текущие снимки: `qa-60/slide-01.png` — `slide-24.png`, `contact-sheet.jpg`, `speaker-notes.png`, `notes-narrow.png`. Это браузерная проверка, а не проведение урока в видеоконференции.

Старые файлы `lesson.json`, `build.py` и `README-legacy-45.md` относятся к прежней 45-минутной версии. Команда `python build.py` перезапишет текущую презентацию старой. Для актуального урока используйте только `build-60.py`. Соседние уроки не изменялись.

# Проверка текущей версии

Дизайнбук: https://github.com/terenta/eduson-kids-design-book, main скачан 3 ноября 2026 года. Базовый CSS и SVG-спрайт перенесены без изменения из `src/lessons/deck_template.py`. Источник и контрольная сумма записаны в `../designbook-source.json`. Эталонные снимки находятся в `reference/`.

| Проверка | Результат |
|---|---|
| Сцена | 1280×720, масштабирование целой сцены |
| Типографика | Inter Tight 800, H1 58 px, H2 44 px; Inter 24 px; JetBrains Mono для запроса |
| Шрифты | Встроены в HTML, включая кириллицу |
| Титул | Фиолетовый фон, орбита, белое окно 820 px, радиус 28 px, точки, крестик, зелёный стикер |
| Контент | Белые слайды, поля 80 px, info-card и ek-note, номер справа внизу |
| Практика | Фиолетовый фон, белое окно с полями 64 px снаружи и 56 px внутри, стикер тайминга |
| Разделители | Зелёный фон, орбита, спич-бабл, без номера страницы |
| Вопросы | Белые слайды с фирменными мятными волнами |
| Основной экран | Только слайды. Нет бокового пульта, iframe, предпросмотра следующего слайда или таймера |
| Заметки | Изначально закрыты, открываются кнопкой «Преподавателю» или N, закрываются N / Escape |
| Публичная копия | В audience.html нет спикерской речи |
| Содержание | Самостоятельный урок без привязки к программированию. Учебный разбор изображений берега и отдельная текстовая практика |
| Проверка | Все 23 слайда просмотрены, внутренние переполнения проверены, 60 минут сохранены |

Изображения берега — специально подготовленные схемы, не фотографии и не результаты настоящей нейросети. Случай ошибки из-за фона — гипотеза для обсуждения. Проверка проведена в браузере; урок в Zoom или Телемост не проводился.
